# Kallopalli — Dashboard de jornadas

Protótipo responsivo feito com HTML, CSS e JavaScript puro. Os dados são fictícios e ficam isolados em um repositório para facilitar a troca por uma API REST no futuro.

## Como executar

Como o projeto usa módulos ES (`type="module"`), execute por um servidor local. Uma opção é abrir a pasta no VS Code e usar a extensão **Live Server**. Também é possível, se Python estiver instalado, executar na pasta do projeto:

```bash
python -m http.server 5500
```

Depois acesse `http://localhost:5500`.
